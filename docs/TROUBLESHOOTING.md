# Проверенные проблемы

## Drive: пустое чтение STATE.json

Симптом: upload успешен, размер 31 209 байт, но readable fetch вернул пустую строку для MIME application/json.
Изменение только MIME на text/plain с теми же JSON-байтами и ID вернуло все 29 472 символа через коннектор.
Издатель AgentSync использует text/plain для .json; формат JSON и расширение сохраняются.
Контроль: читать обратно все шесть файлов и сверять SHA256 до обновления корневого STATE.
Причина внутри коннектора не исследовалась; это проверенный обход, а не исправление его реализации.

## Точка точно на внутреннем ребре PolygonCollider2D

Симптом: при сетке 4 пикселя — 24 пропуска из 90 556, без чужих попаданий; все 77 контрольных участков доступны.
Проверено: аналитический контур содержит точку, native OverlapPoint возвращает true при смещении
в любую из четырёх сторон на 0.00001 world unit. Это случай точности внутренней триангуляции.
Решение в ValidatePixels: требовать попадания со **всех четырёх** сторон с допуском менее 0.002 пикселя.
Геометрия и runtime не раздуваются. Проверка прошла с нулём реальных пропусков и чужих попаданий.
Переключение useDelaunayMesh=false не помогло и было отменено.

## Синтетический ввод пропадает при смене фокуса

Симптом: автонажатия проходят часть цветов и перестают выбирать следующую кнопку; Console без игровых ошибок.
Причина подтверждена настройкой Input System ResetAndDisableNonBackgroundDevices и зависимостью от фокуса Game View.
В тесте временно IgnoreFocus + AllDeviceInputAlwaysGoesToGameView, отдельная синтетическая Mouse.
После этого все 15 цветов прошли дважды. LevelCreationVerification.RemoveTestInput возвращает настройки
и удаляет устройство. Не превращать тестовую настройку в постоянную настройку игры.

## Регистр папки при переносе ресурсов

Симптом: файловый валидатор видит outline/Outline как разные имена; Windows открывает оба варианта.
Решение: двухшаговый AssetDatabase.MoveAsset через временное имя вернул `Outline`, GUID сохранился.
Побайтный и Native-валидаторы прошли. При повторном импорте проверять структуру и хеши `.meta`.

## APK: незавершённое расследование, не «проверенное решение»

Подтверждённый текст: `java.io.IOException: Unable to establish loopback connection`.
Последний BuildReport: Failed, 4 errors, 3 warnings. Unity подготовила сцены/ассеты, Gradle завершился с ошибкой.
Позже обычная PowerShell TCP-проверка loopback прошла; причина ограничения процесса Editor окончательно не установлена.
Решение не подтверждено. Пользователь остановил дальнейшую APK-сборку. Не менять Android/Gradle/пакеты автоматически.
Полный CommandInvokationFailure может включать переменные окружения с секретами: в отчёты передавать только
санитизированный текст ошибки и счётчики, не Editor.log и не весь stack/environment dump.

## Unity AI Account API

Наблюдалось предупреждение `Account API did not become accessible within 30 seconds` из Unity AI Toolkit.
Оно не доказало проблему уровня; Play Mode и проверки работали. Причина/исправление не подтверждены.
Текущие счётчики Console брать из свежего STATE, старое предупреждение не считать текущим без проверки.
