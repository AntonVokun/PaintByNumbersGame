# Архитектурные решения

Записи от 2026-10-18 фиксируют текущие правила; не приписывают автору неизвестные исторические мотивы.

| Решение | Основание и следствие |
|---|---|
| Конвейер 0.4.0: обязательная художественная проверка областей | После `extract` проверяют роли каждого ID и наличие необходимых отдельных художественных деталей; неполная геометрия → CONTOUR_INCOMPLETE и ремонт исходного B/W. Цветовая карта привязана к SHA утверждённого `region_review.json`; это ручная оценка, а не автоматическое распознавание смысловых деталей |
| Конвейер 0.3.0: контур — единственная геометрия | Сначала утверждённый B/W, детерминированные ID областей и SHA, затем отдельно утверждённая карта ID → HEX и программная заливка. Цветной генератор не перерисовывает игровую геометрию; автоматические цветовые подсказки не утверждаются без пользователя. Legacy экспорт сохранён |
| Один PaintZone на цвет | Совместимо с намеренным заполнением всей группы и текущим подсчётом PaintController; островки остаются в одном PNG |
| Без пропущенных контуров между цветами | Каждая смена игрового RGB проходит через видимую тёмную замкнутую границу утверждённого B/W-мастера, а не через бесконтурное пятно; новый preflight отвергает прямое соседство разных групп, визуальная проверка остаётся обязательной |
| Контур первым, видимое утверждение | Обычный запрос новой раскраски возвращает только B/W-контур; цвет после одобрения или команды «Раскрась». Художественный мастер остаётся неизменной геометрией спрайтов; исключение — прямо заказанный полный цикл |
| Новый арт с 30.10.2026 — строгий flat RGB | Все новые зоны содержат ровно один RGB и все островки группы, полный холст 1254×1254; источник проверяет check_flat_source.py до импорта; Art/Unity Play/Android проверяются отдельно |
| Legacy градиентные сцены сохраняем | `layer` и намеренный RGB split остаются для воспроизводимости старых материалов, но не являются стандартом новых иллюстраций; миграция существующих уровней только отдельной задачей |
| Полное полотно у всех слоёв | Одинаковый pivot/PPU сохраняет совмещение без индивидуальных координат и обрезки |
| Общий WinPanel | Одинаковое оформление и уже работающие маршруты кнопок; новые уровни меняют nextLevelSceneName, не панель |
| Сохранить PlayerPrefs | Текущая модель «сцена + цвет» уже работает; добавление контента не требует миграции backend |
| Копия Level_002_New через Editor | Сохраняет шаблон интерфейса, камеры и компонентов; YAML вручную не строится |
| ArtSources вне Assets | Исходники/геометрия не импортируются как игровые ресурсы; SHA256 контролирует сохранность |
| Манифест + внешняя geometry.json | Агент читает короткое описание, а большие координаты обрабатывает код |
| Стабильная карта отдельно от текущего отчёта | docs описывает систему, AgentSync фиксирует дату, HEAD, незакоммиченные изменения и проверки |
| Drive: снимок + STATE последним | Читатель получает целую версию; повторное чтение старого STATE ведёт к неизменяемому снимку |
| Коннектор вместо установки Drive Desktop | Desktop-клиент не обнаружен; текущий связанный аккаунт уже принимает и читает файлы |
| Без автономного облачного shell-демона | PowerShell готовит отчёт, агент запускает готовый publisher с авторизованными MCP tools; токены не сохраняются |

Проверка конвейера на другом реальном изображении и тестирование процесса на Medium остаются отдельными опытами.
Один успешно созданный уровень и синтетические тесты не доказывают универсальность.
