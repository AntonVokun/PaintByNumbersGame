## Совмещение и повторный импорт

Полотно каждого слоя сохраняется полностью, включая прозрачную периферию.
В третьем уровне — 1254×1254, центральный pivot, 100 PPU. Цветовые группы не обрезать по содержимому.
Слой зоны не должен получать дополнительный tint. Чёрный контур — отдельный верхний SpriteRenderer.
Точные Sprite Import настройки и обработка сглаживания — [LEVEL_PIPELINE](LEVEL_PIPELINE.md).

Для явно включённого режима `layer` исходный градиентный RGBA PNG копируется в игровую
папку побайтно, включая скрытые RGB прозрачных пикселей. Представительный RGB кнопки
не заменяет RGB изображения. Согласованное объединение нескольких непересекающихся
слоёв создаёт производный PNG с точными RGBA их видимых пикселей; **все** исходные PNG
сохраняются в Original без изменений. Манифест перечисляет источники и SHA256 каждого.
Пороги alpha для геометрии (128) и hitmask (200), pivot/PPU и полный холст не меняются.
Существующие манифесты и плоские маски используют прежний режим без миграции.

Python сравнивает существующие оригиналы/PNG побайтно и отказывает при отличии;
не создаёт альтернативные имена вроде copy/final2. Манифест фиксирует SHA256 и ID.
Unity импортирует существующий путь с сохранением `.meta`; повторный Create проверяет готовую сцену.
Изменение уже импортированного пути выполняется через AssetDatabase.MoveAsset, с сохранением GUID.
Регистр папок тоже важен для переносимости: текущая структура использует `Outline`, `Zones`, `Previews`.
Нельзя вручную переписывать YAML активных сцен/префабов/ассетов.

Постоянная документация и инструменты готовятся к Git; AgentSync, Logs, Build/Builds, Library и кэши игнорируются.
Большие изображения и бинарные diff в Google Drive AgentSync не передаются.

Level_004 использует такую же структуру Original/Working и Outline/Zones/Previews.
Текущий комплект — «7. кот»: 18 оригинальных масок и 17 игровых PNG после явного объединения 17/18.
