# Игровые системы

Точки входа и точные файлы — [PROJECT_MAP](PROJECT_MAP.md). Здесь описано поведение подтверждённого кода.

## Цветовая группа и применение

Задумано и реализовано в New-уровнях: после выбора цвета нажатие на один его участок
показывает все участки этого цвета. Это намеренное поведение.

Один PaintZone соответствует одному полному PNG, который может содержать много раздельных островков.
OnMouseDown вызывает Paint; Paint проверяет enabled, IsPainted и SelectColor.CurrentColorId.
При совпадении запускается alpha-анимация всего SpriteRenderer (0 → 1 за 0.25 секунды), звук,
сброс таймера подсказки и PaintController.ZonePainted(colorId).

**Граница реализации:** если создать несколько PaintZone с одинаковым ID, Paint() анимирует только
тот объект, по которому нажали, а ZonePainted() списывает **все** оставшиеся зоны данного ID
и сохраняет цвет завершённым. Другие объекты сразу не перекрашиваются.
Поэтому конвейер сохраняет один объект на цвет; это не повод менять задуманную групповую механику.

## Палитра и подсказка

SelectColor.Select увеличивает кнопку в 1.2 раза, записывает CurrentColorId, останавливает прошлые подсказки,
подсвечивает соответствующие группы alpha=0.55. Через 10 секунд без применения включается HintPulse.
Смена цвета и применение сбрасывают подсказку. Завершённая кнопка за 0.25 секунды уменьшается,
исчезает и вызывает PaletteDragScroll.RefreshLayout.
Камера обрабатывает mouse/touch отдельно и блокирует свои жесты над TopBar/PaletteWindow.

## Контроллер, завершение и переход

PaintController.Awake устанавливает singleton; Start скрывает WinPanel, использует назначенные массивы
или находит группы/кнопки, считает остатки, регистрирует ID и загружает прогресс.
ZonePainted списывает цвет целиком, сохраняет его и скрывает соответствующую кнопку.
Когда остаток равен нулю, сохраняется завершение и запускается replay:
0.5 секунды ожидания, скрытие цветов, 0.3 секунды паузы, повторное появление групп с интервалом 0.08 секунды,
затем 1.2 секунды ожидания. Следующее mouse/touch-нажатие показывает WinPanel.
LoadNextLevel проверяет имя и Application.CanStreamedLevelBeLoaded перед LoadScene.

## Сохранение

SaveSystem хранит PlayerPrefs:

| Ключ | Значение |
|---|---|
| `<scene>_Completed` | Уровень завершён |
| `<scene>_Color_<id>_Painted` | Группа цвета завершена |
| `<scene>_ColorIds` | Список зарегистрированных ID |
| `<scene>_ResetPending` | Завершить очистку фактических ID при загрузке сцены |
| `SoundEnabled` | Общая настройка звука |

PrepareLevelProgress применяет отложенный сброс и регистрирует фактические ID.
LoadProgress вызывает SetPaintedInstant и прячет восстановленные кнопки.
ResetLevelsProgress обрабатывает список MainMenuController.levelSceneNames: новый уровень надо добавить туда.
PlayerPrefs.Save вызывается при изменениях. Идентичность уровня связана с именем сцены;
переименование требует миграции, иначе прогресс будет выглядеть потерянным.

## Номера и диагностика

PaintZone.Awake → DisableZoneLabels и SelectColor.Awake → DisablePaletteLabels явно выключают дочерние
объекты с MonoBehaviour пространства TMPro. Скрытие намеренное и не связано с ошибкой PNG/шрифта.
Код не содержит исторического обоснования выбора дизайна; включать номера без согласования нельзя.
ProjectScanner проверяет PaintZone, PaintController, SelectColor и наличие Collider2D,
но не доказывает отсутствие отверстий/чужих попаданий. Для этого есть отдельная проверка конвейера.
