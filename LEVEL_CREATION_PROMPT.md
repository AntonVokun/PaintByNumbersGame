# Промт следующего уровня

Создай следующий уровень «Умной раскраски» из **[название или папка исходников]**:
номер **[NNN]**, название **[название]**, особые требования **[если есть]**.
Сначала прочитай AGENTS.md, затем docs/LEVEL_PIPELINE.md и LEVEL_CREATION_CHECKLIST.md. Для новых иллюстраций применяй стандарт 1254×1254: один цвет палитры = ровно один RGB = один полный Zone_XXX.png со всеми островками; не допускай градиенты и разноцветные непрозрачные пиксели внутри одного Zone. Прогони check_flat_source.py перед Unity-импортом; в штатной Import-NewLevel.ps1 эта проверка включена по умолчанию.
Если источник — только утверждённый чёрно-белый контур, сначала выполни Smart Coloring Pipeline 0.3.0: `locked_region_pipeline.py extract`, покажи карту ID, предложи цвета, дождись одобрения `color_plan.json` и только затем `build` с `verify_flat.py`. НЕЛЬЗЯ заново генерировать цветную иллюстрацию; цвет создаётся только Python-заливкой по B/W. Неподтверждённая палитра = BLOCKED, источник не передавать в Unity. Если уже есть утверждённые готовые Game PNG, художественную подготовку не повторять.
Используй готовую команду Tools/LevelCreation/Import-NewLevel.ps1 и открытый официальный Unity CLI/MCP;
не исследуй заново всю архитектуру. Сохрани Original в ArtSources, игровые PNG — по структуре манифеста.
Не обрезай полотно, не меняй старую графику, runtime и WinPanel без необходимости.
После статического импорта выполни Play Mode и разрешённые текущими указаниями Android-проверки,
сохрани/восстанови пользовательский прогресс. Остановленную пользователем APK-проверку не возобновляй.
Для уже существующих градиентных уровней сохраняй исходные данные, используй legacy-режим только явно и не выполняй миграцию без отдельной задачи. При неоднозначных материалах, ошибках строгой проверки или необходимом изменении механики сначала объясни проблему.
Обнови затронутую карту, сформируй AgentSync и опубликуй через коннектор по docs/AGENT_SYNC_GUIDE.md.
