# Правила для агентов

- Это мобильная 2D-раскраска по номерам. Не ломайте существующие уровни и переходы между сценами.
- Считайте `Assets/_Project/Scenes/Level_002_New.unity` техническим эталоном. Включены `MainMenu.unity`, `Level_001_New.unity`, `Level_002_New.unity`, `Level_003_New.unity`. Не подменяйте их отключёнными legacy-сценами без явного запроса.
- Перед любыми изменениями выполняйте `git status --short --branch`. Не перезаписывайте и не откатывайте чужие незавершённые изменения.
- Не меняйте сцены и ассеты вне текущей задачи. Не удаляйте, не перемещайте и не переименовывайте ассеты или `.meta`-файлы без явного указания пользователя.
- Работайте через открытый Unity Editor и подключённый Unity CLI/MCP; сначала используйте проверки только для чтения. Не запускайте второй Editor для того же проекта.
- После изменений дождитесь окончания импорта и компиляции, затем проверьте Unity Console на новые ошибки. В Play Mode проверьте изменённый уровень и `Level_002_New.unity`; учитывайте сообщения `ProjectScanner`.
- Если изменения затрагивают runtime, сцены, пакеты или настройки сборки, дополнительно проверьте Android-сборку из включённых Build Settings сцен. Для headless-сборки сначала закройте Editor.
- Не обновляйте версию Unity или пакеты проекта без необходимости текущей задачи. При новых ошибках остановитесь, сохраните точный текст ошибки и сообщите пользователю.

## Короткий вход в проект

Сначала читайте этот файл, затем **только относящуюся к задаче** документацию из [индекса](docs/INDEX.md).
Не повторяйте полный аудит. Текущее состояние и незакоммиченные результаты находятся в игнорируемом `AgentSync/STATUS.md`, если он существует; проверяйте дату и HEAD.

| Задача | Основной источник |
|---|---|
| Архитектура, компоненты и зависимости | [PROJECT_MAP](docs/PROJECT_MAP.md) |
| Сцены, меню, камера и WinPanel | [SCENE_MAP](docs/SCENE_MAP.md) |
| Раскрашивание, подсказки и сохранения | [GAMEPLAY_SYSTEMS](docs/GAMEPLAY_SYSTEMS.md) |
| Создать следующий уровень | [LEVEL_PIPELINE](docs/LEVEL_PIPELINE.md) |
| Исходники, PNG, GUID и повторный импорт | [ASSET_STRUCTURE](docs/ASSET_STRUCTURE.md) |
| Известная проблема | [TROUBLESHOOTING](docs/TROUBLESHOOTING.md) |
| Решения и ограничения | [DECISIONS](docs/DECISIONS.md) |
| Обмен с другим ChatGPT | [AGENT_SYNC_GUIDE](docs/AGENT_SYNC_GUIDE.md) |

Механика: выбрать цвет, затем применить его к одному участку — раскрашиваются все участки этого цвета.
В текущих уровнях один `PaintZone` содержит полный PNG цветовой группы с раздельными островками.
Не создавайте несколько PaintZone с одним colorId без проверки GAMEPLAY_SYSTEMS.
Числовые TMP-подписи намеренно скрываются существующим кодом; не включайте их без согласования.
Основные runtime-скрипты — `Assets/_Project/Scripts/`, общий WinPanel — `Assets/_Project/UI/WinPanel/`.

## Завершение задачи

- Обновляйте только затронутые разделы: сцена → SCENE_MAP; компонент → PROJECT_MAP; механика → GAMEPLAY_SYSTEMS; конвейер → LEVEL_PIPELINE; решение → DECISIONS; подтверждённая проблема → TROUBLESHOOTING.
- Обновите инвентарь и проверьте пути: `Tools/Update-ProjectInventory.ps1 -ValidateDocs`.
- Сохраните краткие факты проверок в `AgentSync/observations.json`, затем запустите `Tools/Generate-AgentReport.ps1`.
- Опубликуйте **только проверенные текстовые отчёты** через существующий коннектор Drive по AGENT_SYNC_GUIDE. Для этого уже авторизована проектная папка обмена; новая публичная рассылка не требуется.
- Не включайте Editor.log, дампы окружения, пароли, токены, весь проект или PNG в обмен. При обнаружении секрета остановите публикацию.
- Не делайте commit/push без отдельной команды. Отчёт локальных изменений не является публикацией в GitHub.
- Явная остановка проверки пользователем имеет приоритет: фиксируйте `not_run`/`stopped_by_user`, не возобновляйте APK автоматически.
